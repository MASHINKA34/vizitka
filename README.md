# VoiDteam

## Описание

VoiDteam — одностраничный сайт-портфолио команды веб-разработчиков.
Страница знакомит с командой, показывает выполненные проекты, перечень
услуг с ценами, используемый стек технологий и контакты. Оформление
тёмное, в космическом стиле: анимированный звёздный фон на canvas,
плавное появление блоков при прокрутке и адаптивная вёрстка под телефон,
планшет и десктоп.

Разделы страницы:

- Главная — заголовок, краткое описание и кнопки перехода к разделам;
- Команда — карточки участников с навыками и ссылками;
- Проекты — выполненные работы с описанием, стеком и сроками;
- Услуги — варианты заказа с ценами и сроками;
- Технологии — стек по направлениям (frontend, backend, devops, mobile);
- Контакты — способы связи с каждым участником.

## Технологии

- React 18 и TypeScript
- Vite — сборка и dev-сервер
- Tailwind CSS — стили
- lucide-react — иконки
- Canvas 2D — анимированный звёздный фон (src/components/CosmicBackground.tsx)
- ESLint — проверка кода

Анимации сделаны на чистом CSS и IntersectionObserver, без сторонних
библиотек анимации.

## Требования

- Node.js 18 или новее
- npm

## Установка

Из корня проекта:

    npm install

## Запуск

Dev-сервер с горячей перезагрузкой:

    npm run dev

После запуска сайт открывается по адресу http://localhost:5173

## Сборка

Готовая сборка появляется в папке dist:

    npm run build

Просмотр собранной версии локально:

    npm run preview

## Проверка кода

Линтер:

    npm run lint

Проверка типов:

    npm run typecheck
